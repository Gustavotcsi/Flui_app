# 💸 Flui

> **Gestão Financeira Simplificada.**

O **Flui** é um aplicativo mobile desenvolvido para ajudar usuários a assumirem o controle de suas finanças pessoais de forma intuitiva, rápida e eficiente. O objetivo é transformar a complexidade do controle de gastos em uma experiência fluida.

---

## 📱 Sobre o Projeto

Este projeto nasceu da necessidade de criar uma ferramenta de gestão financeira que fosse ao mesmo tempo robusta e fácil de usar. O app permite o cadastro de receitas e despesas, visualização de saldo e acompanhamento de movimentações.

### 🚀 Funcionalidades Principais
* **Controle de Fluxo:** Registro rápido de receitas e despesas.
* **Categorização:** Organização de gastos por categorias (Alimentação, Transporte, Lazer, etc.).
* **Dashboard:** Visão geral do saldo atual e movimentações recentes.
* **Integração em Nuvem:** Sincronização de dados em tempo real utilizando serviços Google.
